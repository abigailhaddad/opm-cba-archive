# OPM collective bargaining agreements

A copy of every federal union contract in OPM's public database, with a first pass at which ones have been terminated under the executive orders that removed agencies from collective bargaining.

The PDFs and extracted text are on Hugging Face: [link]. This repo has the metadata, the termination flags, the sources behind them, and the scripts. Current counts are in [`data/SUMMARY.md`](data/SUMMARY.md), which is generated from the data.

## Termination flags

Each agreement gets one flag in `data/cba_agreements.csv`:

- `confirmed`: an agency document or court record names the agency and the union
- `confirmed_secondary`: only press reports name them
- `confirmed_then_reinstated`: terminated, then restored by a court
- `inferred`: the agency ended "all" its agreements in some category and this one falls in it (mostly DoD). This isn't a finding; DoD's order itself couldn't be downloaded, so what it says comes from news coverage and a DFAS memo that cites it.
- `uncertain_injunction`: the union was protected by a court injunction whose current status isn't checked
- `uncertain_certification`, `not_flagged_exempt_psf`: DoD units that may be carved out (certified subdivisions; police and firefighters)
- `not_flagged_no_source_found`: covered by the orders, but no termination source found
- `not_flagged_agency_not_named`: at an agency the orders don't cover

OPM requires covered agencies to report the status of every agreement to OPM monthly. That spreadsheet would be the real list. It isn't public.

Court and injunction status goes stale fast; `METHODS.md` says how current it is. Check before relying on any single flag.

## Files

- `data/cba_agreements.csv`: one row per agreement, with OPM's fields, file hash, text status and termination flag
- `data/terminations/sources.csv`: every source behind a flag, with links
- `data/SUMMARY.md`: counts, generated by `scripts/summary.py`
- `METHODS.md`: how it was built, with the full counts and caveats for each pull
- `scripts/`: `download.py`, `extract.py`, `build_table.py`, `summary.py`
